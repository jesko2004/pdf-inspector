# PDF 资料库桌面版

双击项目目录中的 `PDF资料库.exe`，资料库直接显示在独立窗口中。等待启动完成后即可导入 PDF、查询和管理知识库，不需要打开浏览器，也不需要另留一个启动器窗口。当前桌面版和界面版本为 `2026.10.08.4`。

关闭窗口时，程序会正常停止自己启动的本机服务；下次双击打开，继续使用已保存的资料。本程序不会结束启动前已经运行的 Ollama 或其他服务。启动尚未完成时关闭窗口，也会等待启动任务结束并清理自己创建的服务。

## 已有资料与记忆

原文件、提取内容、索引和知识库继续保存在 `.pdf-inspector-data/ollama-local`，沿用网页版的数据，无需重新导入。

桌面窗口的选择记录保存在 `.pdf-inspector-data/desktop-profile`。首次从浏览器切换到桌面窗口时，已有知识库会自动列出，选择一次要用的知识库即可；此后会记住选择。浏览器以前的选择记录不会自动迁移到独立窗口。不要删除上述资料目录。

没有知识库时，自动建立“我的资料”。“新知识库名称”初始为空，灰色文字只是填写提示；需要分类时输入名称并点击“创建”。创建成功后输入框会清空。

## 导入、查询与更新

1. 首次导入：选择“新增资料”，选择 PDF，点击“保存资料”。等待“已保存”后再查询。
2. 再次查询：在“已导入的资料”点击“查询此资料”，或者在查询范围中选择全部资料。无需重复导入。
3. 更新简历：点击原文件旁的“更新此资料”，选择新版 PDF，再点击“更新并保存”。文件名可以不同，更新后仍保留在原来的位置，不新增重复条目。
4. 内容完全相同的 PDF 会跳过重复上传和索引。需要保留旧原文件时，请自行备份。

## 删除不用的知识库

在下拉框中选择知识库，点击红色“删除知识库”，核对名称和资料数量后确认。删除该知识库的入库内容、索引和问答记录，不影响其他知识库或电脑上的原始 PDF。正在入库时要等待完成。启用鉴权时，需要管理员密钥。

删除最后一个知识库后，桌面窗口会保持空列表，重新打开也不会自动建回默认库；需要时手动创建新的知识库。

## 连接与故障

本机未配置鉴权时，API 密钥留空。它是资料库服务的访问密码，不是模型平台密钥；程序不会保存它。通常会自动加载知识库，需要手动刷新时点击“加载知识库”。顶部“重新加载”用于重新载入整个界面。

启动失败时，界面会显示原因，可以点击“重试启动”或“查看日志”。日志位于 `tmp/local-launcher/<本次启动编号>/service.log`。如 8000 端口被占用，先正常关闭原来的资料库服务；本程序不会抢占已有服务。

桌面界面使用 Microsoft WebView2。这台电脑已安装所需运行时；如果其他电脑提示缺少运行时，需要先安装微软 WebView2 Runtime。启动程序不会自行下载模型或运行时。

新电脑首次准备所需的 Python 环境、Rust 扩展和本地模型命令，见 [README 桌面端说明](../../README.md#windows-桌面端exe)。默认配置来自本目录的 `use-ollama.ps1`；已有 `.codex-tools/use-ollama.ps1` 时优先沿用。

## 程序文件与构建

这是依赖当前项目和本机环境的桌面入口。保留 `PDF资料库.exe`、`PDF资料库.exe.config`、`desktop-runtime`、`backend`、`tools`、`.codex-tools` 以及原有资料目录。单独复制 exe 到另一台电脑不能使用。

内嵌窗口复用现有资料库界面和本机后台；不依赖浏览器标签页。WebView2 SDK 使用固定版本 `1.0.4258.31`，构建时校验 SHA256，并在 `desktop-runtime` 中保留许可文件。SDK 的发布和运行时部署方式参见[微软官方文档](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution)。

重新构建：在 PowerShell 运行 `tools/local-launcher/build.ps1`。首次构建会从 NuGet 下载固定 SDK，后续使用本地缓存；需要 .NET Framework 编译器。

桌面验收：运行 `tools/local-launcher/test-desktop.ps1`，分四次实际启动 exe，验证导入、关闭重开、原位更新、查询、删除确认及删除后空列表。仅使用项目 `tmp` 下的独立测试资料和界面配置；报告与界面截图也写入该测试目录。不要同时运行正式资料库，因为都使用本机 8000 端口。
