## 状态与人工复核

Rust 提取器本身不执行 OCR；可选后端处理检测器标记的页面，本地 RapidOCR 另对满足受限条件的封面补充识别。补充结果标注 `native+ocr` 并保留原文，失败或没有可用补充结果时要求复核。OCR 置信度描述已识别并保留的文字行，不衡量整页是否完整提取；详细条件和结果字段见 [后端说明](backend.md#per-page-ocr-completion)。

`ready` 表示现有检查未要求人工复核，不保证所有可见文字均已提取，也不保证未检测到的遗漏一定触发 `needs_review`。需要封面品牌、标题、图像文字、手写或印章内容作为证据时，应核对源页，或使用另行验证的处理方式，不能仅凭 `ready` 作出完整性结论。

已知发票的 BSB 候选在源文件中存在冲突，继续保持 `needs_review` 是正确行为。应依据源页核对候选值，不以自动选一个值或改成 `ready` 作为验收目标。
