## 修复边界

封面补充只在本地 RapidOCR 后端生效：可见图片覆盖页面至少 80%，原生文字不超过 200 字符且全部位于外侧 15% 边缘区域，页面未旋转或裁切。选择依据为页面内容和几何位置，不使用样本名、固定词句或文件哈希。Rust CLI 单独运行及未配置 OCR 的后端不会因此获得图像文字识别能力。

原生内容不被 OCR 替换；按位置过滤重复识别后，新增文字进入带页码的 Markdown 和检索片段。结果标注 `native+ocr` 和 `ocr.supplemented_pages`，补充失败或无可用结果时保留原文并要求复核。该路径不保证完整还原页面排版，不支持任意图像文字区域，也不为 bbox 字段提供 OCR 坐标。

标题修复只去掉相邻、同字体同语义标记、尺寸一致且位移极小的重复文字对象；正常位置的重复数字、其他页的相同文字和表单值均保留。中文修复只改变换行连接时新插入的分隔符，未进行文字纠错或删除行内原有空格。
